# 붕세권 (BungSpot)

## 1. 프로젝트 소개
**붕세권(BungSpot)**은 겨울철 길거리에서 운영되는 붕어빵 파는 곳 위치를 지도 기반으로 제공하고,  
간편한 계좌이체와 이체 확인 알림 기능을 통해 소비자와 판매자 모두의 불편을 줄이기 위한 서비스입니다.

일반 지도 서비스에서는 찾기 어려운 붕어빵집의 정보를 쉽고 빠르게 확인할 수 있도록 하여,  
손님에게는 편리한 접근성을 제공하고 사장님에게는 홍보 및 결제 확인의 편의성을 제공합니다.

## 4. 프로젝트 배경
겨울철에만 운영하는 붕어빵집은 길거리에서 장사하는 경우가 많아 일반 네이버지도나 카카오지도에서 찾기 어렵습니다.  
또한 운영 시간이나 위치가 유동적이기 때문에 직접 방문했다가 헛걸음하는 불편함도 발생합니다.  
현재는 SNS를 통해 유명해진 가게의 정보만 일부 공유되고 있어, 우리 동네의 붕어빵 판매 위치를 쉽고 빠르게 확인할 수 있는 서비스가 필요하다고 판단하여 본 프로젝트를 기획하게 되었습니다.

---

## 5. 프로젝트 목적
본 프로젝트는 손님이 우리 동네의 붕어빵 판매점을 쉽게 찾고 편리하게 구매할 수 있도록 돕는 것을 목적으로 합니다.  
동시에 사장님 입장에서는 소액 계좌이체 후 입금 여부를 일일이 확인해야 하는 불편함과,  
이른바 ‘먹튀’ 문제를 줄이고자 합니다.  
또한 지도 기반으로 위치와 정보를 제공함으로써 붕어빵 판매점의 홍보 효과를 높이고 장사 활성화에도 기여하고자 합니다.

---

## 6. 시스템 설명
붕어빵 판매 위치를 지도에 표시하여 사용자가 가까운 판매점을 쉽게 찾을 수 있도록 하고,  
계좌번호 복사 및 간편 송금 기능을 통해 빠른 결제를 지원합니다.  
또한 사장님에게는 이체 확인 알림 기능을 제공하여 결제 확인 과정을 더욱 편리하게 만들고,  
소액 거래 과정에서 발생할 수 있는 피해를 줄일 수 있도록 돕는 서비스입니다.

---

## 7. 핵심 기능

### 1) 붕어빵 판매점 정보 등록
- 위치 / 가격 / 맛 종류 / 붕세권페이 송금 계좌번호 등록
- 사장님이 직접 등록 가능
- 사용자가 판매점 등록 요청 가능

### 2) 지도 기반 붕어빵 위치 표시
- Google Maps API를 활용한 위치 기반 서비스
- 붕어빵 판매 위치를 핀으로 표시
- 사용자 현재 위치 기준 주변 1km 이내 판매점 우선 표시

### 3) 커뮤니티 기능
- 붕세권 사용자 간 정보 공유
- 맛집 후기, 운영 여부, 가격 정보 등 소통 가능

### 4) 붕세권페이를 통한 이체 확인 알림
- 손님은 붕세권페이를 연결해 계좌번호를 직접 입력하지 않고 간편 송금 가능
- 사장님은 이체 확인 알림을 받아 입금 여부를 빠르게 확인 가능
- 소액 계좌이체 과정의 불편 감소 및 먹튀 문제 완화
